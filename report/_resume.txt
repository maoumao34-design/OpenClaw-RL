复杂随机物理环境下弹道控制系统的算法对比研究
  2025.11 – 2026.01 | NTU 课程项目
     项目背景：针对一个自制的基于二维物理引擎的弹道投射模拟器，探究监督学习 (SL) 与强化学习
      (PPO) 在应对抖动（Jitter）导致的非线性随机误差时的鲁棒性差异 。
      监督学习 (SL) 的优越实现：
         通过采集“实际着陆坐标”而非“目标坐标”作为训练标签，使 MLP 模型成功学习到了物理引擎的
         潜在偏差 。
         结果：即使在随机噪声干扰下，SL 模型仍能保持极高的预测精度，证明了其在确定性物理反馈
         任务中的稳定性 。
      强化学习 (RL) 的适配性尝试与局限性分析：
        环境适配优化：针对随机抖动环境，尝试通过重塑奖励函数 (Reward Shaping) 以缓解稀疏奖
        励问题，并调整观测空间 (Observation Space) 试图捕捉抖动规律 。
        实验发现：即便进行了环境适配性修改，PPO 模型在噪声环境下的表现仍远逊于 SL 。
        深度归因：通过实验对比得出，由于游戏物理抖动的随机性极高，破坏了强化学习所需的马尔
         可夫动力学稳定性，导致策略梯度难以在剧烈波动的状态空间中收敛 。
      技术产出：独立完成 Python + PyTorch 环境下的算法评估。该项目不仅实现了高精度的弹道模
      型，更通过对比实验论证了“在特定高频物理抖动环境下，传统深度学习优于强化学习”的结论 。

Jump-Tactics Duel   ：自研回合制对战环境与 PPO 智能体训练
 2026.04 – 2026.05 | NTU   课程项目（强化学习）
    项目背景：从零设计并实现一个原创 1v1 蓄力跳跃 + 远程魔法对战游戏，完成 Gymnasium 风格
    环境 → 多 run 训练 → 量化评估 → 视频对比 的端到端 RL pipeline。
    环境与 MDP 形式化：自研 env.py（13 维 observation、Discrete(60) 动作、phase-based 决
    策），自定义两套 reward shaping 模式（完整 shaping 用于射击训练，frozen-attack 简化 reward
    用于移动训练），通过 attack/move credit 拆分解决 phase 间 credit assignment 问题。
    多阶段 PPO 训练 Pipeline（stable-baselines3，总计 6.5M env steps）：组合使用 Entropy
    Annealing（自定义 Callback）+ Shooting → Full 课程学习 + Frozen-Attack Curriculum + 定
    期 Checkpoint 自动评估；最终模型由 4M 步射击预训练 + 三阶段移动训练链（Self-play 500k →
    vs Scripted 1M → vs Scripted 1M warm-restart）组成。
    实验结果：100 局定量评估中，PPO（移动 + 冻结射击）vs scripted 中等强度对手胜率 27%，
    Random 基线 0%；人机对战中作者本人难以战胜该模型；通过代码审计定位 scripted 对手 RNG
    耦合机制，重新校准评估对手强度。
