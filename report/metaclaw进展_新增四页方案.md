## 计分、窗口与口径规则（10-14 确认）

**① 没跑的题不计 0**

| 情况 | 处理 |
|---|---|
| 跑了，答错或 idle timeout | 计 0（真实结果）|
| 跑了，infra failure | 计 0，另外计数 |
| 根本没跑（训练停掉之后的天、最后一天没跑到的轮）| **不计 0，不进分母** |

以前把没跑完当 0，前提是"没跑完 = 跑不完"。CLI 查明：没跑完的六趟**全部是 driver 中途消失**（rollout 无 Python 异常，Ray 仍是 RUNNING，启动脚本 `wait || true` 吞掉了退出码，随后无条件打印"全部跑完"），进程退出本身属于外部原因。所以不再把剩下的天折成 0。未跑完的趟也**不引用 30 天总分**（例：H0 旧的 22.8 / 18.3 是 79.035/346、41/224，分母含没跑的题；按本规则是 33.9 / 26.8）。

**② 窗口按起病日分段，没跑到的段留空**

原定"截到组内最早停下那趟"不可行：纯 OPD 停在 day05 第 8 轮，最后完整天是 day04，消融组和遮罩组会只剩 4 天。改为：按组内各趟的起病日把天数分段，每段内是同天对比；某趟没完整跑到的段留"—"。没跑完的最后一天整天排除。

**③ 起病日统一用"当天 copies≥8 的 main turn 占比 ≥ 25%"**

阈值与 H-e、H-f 实验的判据一致。不用"首个 DROPPED"：KL 趟 day04 就有 DROPPED，却一直健康到 day17。纯 RL 不复读 thinking，单独用"day12 起 Acc 归零"描述。

**④ 每张表加第二趟基线 B0' 作噪声参照**

day01 还没有任何训练步，9 趟都是初始模型，Acc 却在 60.0–70.0 之间；两趟基线 day01–03 窗口差 12 个点（59.6 vs 71.7）。健康期 ±10pt 以内的差异视为噪声。

**⑤ Compl 用 `passed_all`**

与第 5 页同口径（CLI 核对项 ⑧ 确认第 5 页用的是 `passed_all` = 当天 file_check 通过数 / 当天全部题数）。正式 file_check 通过率 `compl_fc` 也在 CSV 里，需要时放脚注。窗口数一律是按题数加总，不是日均。

| 混合（对照）| 68.2 / 33.9 | 58.9 / 33.3 | **21.0 / 10.8** ⚠40% | **0.0 / 0.0** ⚠83% |

- day01–05 各趟差异（67.6–75.6）在两趟基线的差距范围内，不能读成收益

## 第 8 页：机制验证实验 —— 两个假设各一个对照

**H-e：OPD 压低了"停止思考"，模型越想越长**
对照：纯 OPD。实验：纯 OPD + 遮住 OPD 对停止决策和随后动作的作用。

| | day01–03 | day04 | day05–18 |
|---|---|---|---|
| 基线 B0 | 59.6 / 36.4 | 66.7 / 30.0 | 48.5 / 21.9 |
| 基线 B0' | 71.7 / 39.4 | 63.3 / 30.0 | 48.0 / 20.6 |
| 纯 OPD | 74.7 / 39.4 | 36.7 / 10.0 ⚠26% | — |
| 纯 OPD + 遮罩 | 66.7 / 33.3 | 73.3 / 40.0 ⚠26% | **2.8 / 0.0** ⚠97% |

- 遮罩有效：每步 OPD 仍作用的位置占比 0.828–0.975，7 步全在事先定的 [0.8, 1.0) 内
- 两趟都在 day04 起病（复读占比都是 26%），遮罩趟 day05 起几乎全部复读 → **一天没推迟，H-e 否定**；问题出在 OPD 作用于 thinking 内容的部分

**H-f：训练用了旧权重生成的样本**
对照：混合 H0。实验：混合 + 只用当前权重生成的样本。

| | day01–07 | day08 | day09 |
|---|---|---|---|
| 基线 B0 | 60.0 / 35.1 | 54.1 / 25.0 | 37.6 / 18.2 |
| 基线 B0' | 71.6 / 40.3 | 25.0 / 25.0 | 37.6 / 18.2 |
| 混合（对照）| 67.1 / 35.1 | 49.4 / 25.0 | 61.5 / 45.5 ⚠29% |
| 混合 + 同策略 | 63.1 / 31.2 | **0.0 / 0.0** ⚠11% | 23.6 / 0.0 ⚠0% |

- 同策略过滤生效：样本新旧差（`train_rollout_logprob_abs_diff`）多数步回到 step 0 底线附近，此前各趟多为底线的 1.4–2.7 倍
- 到 day09 没有成批复读（对照 day09 为 29%）；但 day09 结束时只训练到 step 7，对照在 day09 起病时已到 step 11，**步数没对齐**
- 同时出现了**别的失效**：day08 有一个 95 turn 的超长轮次被丢弃，当天 Acc 0；day09 Compl 0。day10 不完整、不进窗口，但那半天里已有 copies 76 和 2 次 DROPPED
- **结论只能写"没有复读 thinking，但出现了别的失效，未定论"，不能写成同策略有效**

## 第 9 页：总结（初稿，已做进 PPT，待用户审阅）

一张汇总表 + 四条要点：

| 实验 | 对照 | 成批复读首日（对照 → 实验）| 结论 |
|---|---|---|---|
| 去掉 RL（纯 OPD）| 混合 | day09 → day04 | 复读 thinking 只在开了 OPD 时出现 |
| 去掉 OPD（纯 RL）| 混合 | day09 → 无复读；day12 起 Acc 归零 | 换了一种崩法：反复 write、上下文撑爆 |
| + 熵 0.1 | 混合 | day09 → day06 | 加速崩溃 |
| + KL 0.1 | 混合 | day09 → day18 | 推迟 9 天，挡不住 |
| 遮住停止决策（H-e）| 纯 OPD | day04 → day04 | 一天没推迟，假设否定 |
| 只用当前权重样本（H-f）| 混合 | day09 → 到 day09 无复读 | 步数没对齐、出现别的失效，未定论 |

- ① 零训练基线跑满 30 天不崩；目前所有训练配置都在 30 天内崩溃，没有一趟超过零训练基线
- ② 崩法有两种：开了 OPD → 复读 thinking → idle timeout；纯 RL → 反复 write → 上下文撑爆、压缩超时
- ③ 正则只能改变起病时间：熵提前 3 天，KL 推迟 9 天；两个机制假设中 H-e 已否定，H-f 尚无结论
- ④ 口径：健康期 ±10pt 以内的差异在两趟零训练基线的差距范围内；训练中途停止的趟，没跑到的天不计入
