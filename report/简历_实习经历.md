## 正文

**联想集团 · AI Lab（北京）**　　2026/06 - 2026/10
**通用人工智能研究（实习）**

基于自进化领域综述（*Self-Improving Agents in the Era of Experience*, 2026）梳理技术路线，选定其列为部署后在线学习代表工作的 **OpenClaw-RL** 进行复现：

**前沿论文复现 (Paper Reproduction)：**
- 复现 OpenClaw-RL（arXiv:2603.10165）Personal Agent Track 的 **Hybrid RL** 方法（GRPO + OPD topk-select 混合损失，`L = w_RL·L_GRPO + w_OPD·L_OPD`）；基于 **Megatron-LM + slime 异步 RL 框架、8×H20 分布式训练环境**，训练 Qwen3-4B-Thinking-2507。
- 训练**直接运行于真实 OpenClaw Agent 运行时**（非简化模拟环境），实现对话与训练**异步并行、权重在线更新、全程不停机**——避免训练环境与部署环境不一致导致的迁移失效。
- Separate-Student 设定下**收敛于第 20 个 session，与论文报告值 19.2 基本重合**。

**方法泛化实验 (Method Generalization)：**
- 将已校准的 Hybrid RL 方法迁移至 **MetaClaw-Bench**（arXiv:2603.17187；30 天连续任务流、CLI agent 场景，与原对话场景任务形态完全不同），验证方法普适性；**训练主干不变**，仅改造信号来源与运行环境。
- **信号侧改造**：round 最终轮次的评估与指令信号改由 Benchmark 自带**确定性 checker** 提供（file_check 取 exit code、multi_choice 精确匹配打分），不再依赖 LLM 判官；针对 round 内多轮 tool-call 结构，**新增任务无关的中间轮次步骤判官**（两篇论文均无现成方案）。
- **结果：Acc. 17.8% → 37.3%（+19.5pt）、Compl. 0.0% → 13.9%（首次非零）**，出分口径与论文 Table 1 一致（同一趟训练全程实时聚合）。
- **量级参照**：论文中 Kimi-K2.5 + 完整 MetaClaw 管线为 40.6% / 16.5%，本次以 **4B 模型、仅迁移 RL 方法、不含技能库**达到相近量级（模型量级与评测环境不同，非同条件对比）。

**技术栈：** Python、PyTorch、Megatron-LM、slime、GRPO / PPO、知识蒸馏（OPD）、SGLang、Qwen3、分布式训练、Hugging Face、Git
